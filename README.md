## ℹ️ Overview

The **Ballon d'Or Dashboard** transforms football performance data into an interactive player analysis experience.

Users can begin with **All Candicate** to explore the overall candidate landscape, select a player in **Overview**, and move into **Player Drill Through** for a more detailed statistical profile.

The dashboard combines performance metrics, rankings, achievements, and interactive visuals to make player comparison easier to explore.

## 🛠️ Skills Showcased

*  **Data Transformation & Data Modeling** — Preparing football data for player-level analysis and comparison
*  **DAX Measures** — Creating analytical metrics such as **Rating, G/A per 90 minutes, and Standing Rank**
*  **Data Visualization** — Using Cards, Charts, Tables, Radar Chart, and Heat Map
*  **Interactive Reporting** — Implementing slicers, player selection, navigation, bookmarks, and Drill Through
*  **Dashboard Design** — Building a cohesive Ballon d'Or visual identity with structured information hierarchy

## 🚀 Usage

1. Open the dashboard using the link above.
2. Start from **All Candicate** to explore the candidates.
3. Select a player to update the **Overview**.
4. Use **Player Drill Through** to explore detailed player statistics and performance indicators.

The dashboard is designed to communicate the analysis visually, so most insights can be explored directly through interaction with the report.
